Des livres pour toi

Quelqu'un t'envoie des livres avec l'application Bibliothèque. L'envoi est chiffré : seul ce lien permet de les ouvrir.

Ouvrir dans Bibliothèque Le bouton ne fait rien ? Touche ici
Tu n'as pas encore l'application ?
  1. Télécharge Bibliothèque et installe-la.
  2. Reviens sur cette page (touche de nouveau le lien reçu).
  3. Touche « Ouvrir dans Bibliothèque » : les livres s'ajoutent tout seuls.

Si la page s'est ouverte dans Messenger ou une autre application, choisis d'abord « Ouvrir dans Chrome » (menu ⋮).

Ces livres s'ouvrent avec l'application Bibliothèque pour Android. Ouvre ce lien sur un téléphone Android.

🔒 Les livres sont chiffrés sur le téléphone de l'expéditeur. Le service qui les héberge temporairement ne peut pas les lire. Le lien expire après quelques jours.
