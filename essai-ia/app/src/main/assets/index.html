Cette petite application d'essai reproduit ce que vivra une personne qui installe Bibliothèque sans rien connaître : obtenir sa propre clé gratuite pour l'IA de Google, en quelques touchers.

Essayer l'IA

Un vrai essai avec ta clé : Gemini résume le texte ci-dessous.

Pour l'essai, tu peux effacer la clé et refaire tout le parcours autant de fois que tu veux. Désinstalle « Essai Clé IA » comme n'importe quelle application : ta Bibliothèque n'est pas touchée.

IA gratuite en 1 minute

Google offre gratuitement son IA, Gemini. Il faut seulement une « clé » : un code personnel qui dit à Google que c'est toi.

Ce qui va se passer :
  1. La page de Google s'ouvre en bas de l'écran.
  2. Les 3 touchers à faire restent écrits ici, en haut.
  3. Tu appuies sur « Créer une clé API », « Créer une clé », puis sur les deux petits rectangles pour copier.
  4. Tu appuies sur le bouton vert : la page se ferme et l'application trouve la clé toute seule.

✔ Gratuit, aucune carte de crédit.
✔ La clé reste seulement sur ce téléphone.
ℹ️ Avec l'offre gratuite, Google peut utiliser les textes envoyés pour améliorer son IA.

Dans la page de Google en bas, fais ces 3 touchers :
1Appuie sur Créer une clé API en haut à droite
2Une fenêtre s'ouvre : appuie sur Créer une clé en bas à droite
3Va au bout de la ligne Clé API et appuie sur le petit carré Ça fait une copie.

Pour la retrouver :
  1. Retourne sur la page de Google.
  2. Dans la liste, ta clé est la ligne bleue … (par exemple « …3YIw »).
  3. Appuie sur les deux petits rectangles sur la même ligne.

Coller la clé
