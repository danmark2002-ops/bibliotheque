IA gratuite en 1 minute

Google offre gratuitement son IA, Gemini. Il faut seulement une « clé » : un code personnel qui dit à Google que c'est toi.

Ce qui va se passer :
  1. La page de Google s'ouvre en bas de l'écran.
  2. Les instructions restent ici, en haut, étape par étape.
  3. Tu touches « Créer une clé API », puis « Copier ».
  4. Tu reviens : l'application trouve la clé toute seule.

✔ Gratuit, aucune carte de crédit.
✔ La clé reste seulement sur ce téléphone.
ℹ️ Avec l'offre gratuite, Google peut utiliser les textes envoyés pour améliorer son IA.
